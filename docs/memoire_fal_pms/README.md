# Dossier Mémoire - FAL PMS

## Fichier principal
- `MEMOIRE_FAL_PMS_LICENCE.md`
- `MEMOIRE_FAL_PMS_LICENCE.docx`

## Illustrations
- `assets/` : captures + graphiques + architecture
- `diagrams/` : diagrammes MERISE (MCC, MCD, MLD, MPD, MCT, MOT)

## Export Word / PDF
1. Ouvrir `MEMOIRE_FAL_PMS_LICENCE.md` dans VS Code / Word.
2. Exporter en `.docx` (Word) ou `.pdf`.

## Génération DOCX locale
- Script: `generate_docx.ps1`
- Commande:
  ```powershell
  powershell -ExecutionPolicy Bypass -File docs\memoire_fal_pms\generate_docx.ps1
  ```

## Note Word
- À l'ouverture du `.docx`, faire clic droit sur la table des matières puis **Mettre à jour le champ**.
